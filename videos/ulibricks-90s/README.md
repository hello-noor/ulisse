# ULIBRICKS in 90 secondi

Video promo 9:16 (1080×1920) fatto con le riprese del gioco vero (`assets/v/`), registrate dal motore 3D dell'app, e grafica HyperFrames sopra.

- `ulibricks-90s-web.mp4`: il video finito (versione leggera).
- `tools/build.mjs`: genera `index.html` (montaggio, didascalie, schede, finale con QR).
- `tools/make-music.mjs`: genera la musica di sottofondo.
- Render: `npm run render` (richiede `npx hyperframes`).
